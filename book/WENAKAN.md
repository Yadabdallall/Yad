# ڕێنمایی وێنەکان — «سەرۆک کۆماری یاریگا»

کتێبەکە ٢٨ شوێنی وێنەی تێدایە. ٥ـیان دانراون؛ ٢٣ـیان ماون.

## چۆن وێنەیەک دادەنێیت

١. وێنەکە دابەزێنە.
٢. ناوەکەی بگۆڕە بۆ ئەو ناوەی لە خشتەکەی خوارەوەدا هاتووە (ڕێک وەک خۆی).
٣. بیخەرە ناو `book/images/`.
٤. ئەم فەرمانە جێبەجێ بکە:

```bash
BOOK_TOKENS=0 python3 scripts/build.py
```

وێنەکە بە خۆکارانە لە شوێنی خۆیدا دادەنرێت و چوارچێوەی «شوێنی وێنە» لادەچێت.

> **ئاگاداری:** دوای زیادکردنی وێنە، ژمارەی لاپەڕەکان دەگۆڕێت. بۆ گەڕانەوە بۆ ٢٠٦ لاپەڕە، بڕوانە `README.md`.
