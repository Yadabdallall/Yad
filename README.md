# سەرۆک کۆماری یاریگا

**مێژووی سیاسیی وەرزش لە عێراق — لە سێبەری ستەمکارییەوە بۆ چەترە گەورەکەی مام جەلال**

نووسینی: سۆلینی قەرەغەرمان

کتێبێکی ٢٠٦ لاپەڕەیی بە کوردیی سۆرانی، بە فۆرماتی Word (.docx).

---

## دەرئەنجام

```
build/serok_komari_yariga.docx    ← کتێبەکە، ٢٠٦ لاپەڕە
```

## دروستکردنەوەی کتێبەکە

```bash
pip install python-docx Pillow pypdf
BOOK_TOKENS=0 python3 scripts/build.py
```

## پێکهاتەی پڕۆژەکە

```
book/src/       دەقی کتێبەکە — ١٢ فایلی .md بە ڕیزبەندی
book/images/    وێنەکان (٥ دانراوە، ٢٣ ماوە — بڕوانە book/WENAKAN.md)
scripts/
  docxkit.py    کیتی OOXML بۆ ڕاست-بۆ-چەپ، ڕەنگ و چوارچێوە
  build.py      دروستکەری سەرەکی — .md → .docx
  measure.py    پێوانەی لاپەڕەکان و دروستکردنی پێڕستی ناوەڕۆک
  fit.py        ڕێکخستنی درێژی کتێبەکە بۆ ژمارەیەکی دیاریکراو
build/          دەرئەنجام
```

## ڕازاندنەوە

| تەوەر | بەها |
|---|---|
| قەبارەی لاپەڕە | A5 (١٤.٨ × ٢١ سم) |
| فۆنتی دەق | Noto Naskh Arabic، ١١.٥ خاڵ |
| فۆنتی سەردێڕ | Noto Kufi Arabic |
| ڕەنگی سەرەکی | سەوزی تۆخ `#14532D` / `#0F3D26` |
| ئاراستە | ڕاست-بۆ-چەپ (bidi) |
| پێڕستی ناوەڕۆک | خۆکار، بە ژمارەی پەڕەی ڕاستەقینە |

ئەگەر فۆنتەکان لەسەر کۆمپیوتەرەکەت نین:
[Noto Naskh Arabic](https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic) ·
[Noto Kufi Arabic](https://fonts.google.com/noto/specimen/Noto+Kufi+Arabic)

## زمانی نیشانەکردن

دەقی کتێبەکە بە زمانێکی سادە نووسراوە:

```
@PART یەکەم | ناونیشان | ژێرناونیشان     پەڕەیەکی تەواو بۆ دەستپێکی بەش
@H1 / @H2 / @H3                           سەردێڕەکان
@LEAD                                     بڕگەی پێشەوە
@QUOTE دەق | ناوی خاوەنەکەی               چوارچێوەی وتە
@BOX ناونیشان ... @ENDBOX                 چوارچێوەی زانیاری
@LIST / @NUM ... @END                     لیست
@TABLE ناونیشان ... @ENDTABLE             خشتە
@IMG فایل | پێناسە | سەرچاوە              وێنە
@NOTE / @SIG / @HR / @PB                  تێبینی، واژۆ، جیاکەرەوە، پەڕەبڕ
```

## پاراستنی ٢٠٦ لاپەڕە

دوای هەر گۆڕانکارییەک لە دەق یان وێنەکاندا، ژمارەی لاپەڕەکان دەگۆڕێت.
بۆ گەڕانەوە بۆ ٢٠٦:

```bash
python3 scripts/fit.py 206
```

ئەمە بۆشاییی نێوان دێڕەکان بە وردی ڕێک دەخات تا کتێبەکە ڕێک دەکەوێتە
سەر ٢٠٦ لاپەڕە. بەهای ئێستا: `BOOK_BODY_LINE=1.42`.

بۆ پشکنینی دەستی:

```bash
python3 scripts/build.py && python3 scripts/measure.py
```

## تێبینی لەسەر ژمارەی لاپەڕە لە فوتەردا

فایلەکە بە `w:pgNumType w:fmt="hindiNumbers"` ڕێکخراوە، واتە ژمارەی
لاپەڕەکان دەبێت بە ٠–٩ی کوردی دەربکەون لە Word. ئەگەر بە ژمارەی لاتینی
دەرکەوتن، لە Word: دووگرتە لەسەر فوتەرەکە ← کلیکی ڕاست لەسەر ژمارەکە ←
**Format Page Numbers** ← جۆری ژمارە بگۆڕە بۆ ١، ٢، ٣.

## ڕاستکردنەوە گرنگەکان لە دەقی سەرەتاییدا

سێ خاڵی نادروست لە دەقی سەرەتاییدا ڕاست کراونەتەوە — بڕوانە بەشی چوارەمی کتێبەکە.
