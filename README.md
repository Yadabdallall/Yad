# سەرۆک کۆماری یاریگا

**مێژووی سیاسیی وەرزش لە عێراق — لە سێبەری ستەمکارییەوە بۆ چەترە گەورەکەی مام جەلال**

نووسینی: سۆلینی قەرەخەرمان

کتێبێکی ٢٠٦ لاپەڕەیی بە کوردیی سۆرانی، بە فۆرماتی Word (.docx).

---

## دەرئەنجام

```
build/serok_komari_yariga.docx    ← کتێبەکە، ٢٠٦ لاپەڕە
```

## دروستکردنەوەی کتێبەکە

```bash
pip install python-docx Pillow pypdf
BOOK_TOKENS=0 python3 scripts/build.py
```

## پێکهاتەی پڕۆژەکە

```
book/src/       دەقی کتێبەکە — ١٢ فایلی .md بە ڕیزبەندی
book/images/    وێنەکان (٥ دانراوە، ٢٣ ماوە — بڕوانە book/WENAKAN.md)
scripts/
  docxkit.py    کیتی OOXML بۆ ڕاست-بۆ-چەپ، ڕەنگ و چوارچێوە
  build.py      دروستکەری سەرەکی — .md → .docx
  measure.py    پێوانەی لاپەڕەکان و دروستکردنی پێڕستی ناوەڕۆک
  fit.py        ڕێکخستنی درێژی کتێبەکە بۆ ژمارەیەکی دیاریکراو
  add_sources.py  بڵۆکی سەرچاوەکان لە کۆتایی هەر بەشێکدا دادەنێت
build/          دەرئەنجام
```

## ڕازاندنەوە

| تەوەر | بەها |
|---|---|
| قەبارەی لاپەڕە | A5 (١٤.٨ × ٢١ سم) |
| فۆنت | Times New Roman (دەق و سەردێڕ)، ١١ خاڵ |
| ڕەنگی سەرەکی | سەوزی تۆخ `#14532D` / `#0F3D26` |
| ئاراستە | ڕاست-بۆ-چەپ (bidi) |
| پێڕستی ناوەڕۆک | کورت — تەنها بەش و بابەتەکان، بە ژمارەی پەڕەی ڕاستەقینە |
| بەستەرەکان | ٧٢ بەستەری کلیک‌کراو بۆ پشتڕاستکردنەوە |

### ⚠ گرنگ — فۆنت و پیتە کوردییەکان

کتێبەکە بە **Times New Roman** داڕێژراوە، وەک داوا کراوە.

هەندێک وەشانی کۆنی Times New Roman هەموو پیتە کوردییەکان (ڕ، ڵ، ۆ، ێ، ە، ڤ)
لەخۆ ناگرێت. ئەگەر لە Word هەندێک پیت بە شێوەیەکی جیاواز دەرکەوتن، دوو
چارەسەر هەیە:

١. وەشانێکی نوێی Office/Windows بەکاربهێنە (فۆنتەکەی تەواوترە).
٢. یان فۆنتەکە بگۆڕە و دووبارە دروستی بکەرەوە:

```bash
BOOK_FONT="Noto Naskh Arabic" BOOK_TOKENS=0 python3 scripts/build.py
python3 scripts/fit.py 206
```

[Noto Naskh Arabic](https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic)
فۆنتێکی بێبەرامبەرە و هەموو پیتە کوردییەکان لەخۆدەگرێت.

> **تێبینیی ئەمانەتی:** ژمارەی ٢٠٦ لاپەڕە لە ژینگەی دروستکردندا پێوانە کراوە،
> کە Times New Roman ـی ڕاستەقینەی تێدا نەبوو و فۆنتێکی جێگرەوە بەکارهات.
> پێوانەکانی فۆنتی ڕاستەقینە دەکرێت کەمێک جیاواز بن، بۆیە ڕەنگە لە Word
> ـدا ژمارەکە چەند لاپەڕەیەک بجوڵێت. `scripts/fit.py 206` ئەمە ڕاست
> دەکاتەوە.

## زمانی نیشانەکردن

دەقی کتێبەکە بە زمانێکی سادە نووسراوە:

```
@PART یەکەم | ناونیشان | ژێرناونیشان     پەڕەیەکی تەواو بۆ دەستپێکی بەش
@H1 / @H2 / @H3                           سەردێڕەکان
@LEAD                                     بڕگەی پێشەوە
@QUOTE دەق | ناوی خاوەنەکەی               چوارچێوەی وتە
@BOX ناونیشان ... @ENDBOX                 چوارچێوەی زانیاری
@LIST / @NUM ... @END                     لیست
@TABLE ناونیشان ... @ENDTABLE             خشتە
@IMG فایل | پێناسە | سەرچاوە              وێنە
@SRC ... @ENDSRC                          سەرچاوەکانی بەشەکە
@NOTE / @SIG / @HR / @PB                  تێبینی، واژۆ، جیاکەرەوە، پەڕەبڕ
```

## پاراستنی ٢٠٦ لاپەڕە

دوای هەر گۆڕانکارییەک لە دەق یان وێنەکاندا، ژمارەی لاپەڕەکان دەگۆڕێت.
بۆ گەڕانەوە بۆ ٢٠٦:

```bash
python3 scripts/fit.py 206
```

ئەمە بۆشاییی نێوان دێڕەکان بە وردی ڕێک دەخات تا کتێبەکە ڕێک دەکەوێتە
سەر ٢٠٦ لاپەڕە. بەهای ئێستا: `BOOK_BODY_SIZE=11.0`، `BOOK_BODY_LINE=1.39`، `BOOK_BODY_AFTER=5.0`.

ئەگەر بتەوێت کتێبەکە درێژتر بێت لە ٢٠٦ لاپەڕە، تەنها ژمارەکە بگۆڕە:
`python3 scripts/fit.py 240`.

بۆ پشکنینی دەستی:

```bash
python3 scripts/build.py && python3 scripts/measure.py
```

## تێبینی لەسەر ژمارەی لاپەڕە لە فوتەردا

فایلەکە بە `w:pgNumType w:fmt="hindiNumbers"` ڕێکخراوە، واتە ژمارەی
لاپەڕەکان دەبێت بە ٠–٩ی کوردی دەربکەون لە Word. ئەگەر بە ژمارەی لاتینی
دەرکەوتن، لە Word: دووگرتە لەسەر فوتەرەکە ← کلیکی ڕاست لەسەر ژمارەکە ←
**Format Page Numbers** ← جۆری ژمارە بگۆڕە بۆ ١، ٢، ٣.

## سیستەمی سەرچاوەکان

لە کۆتایی هەر بەشێکدا چوارچێوەیەکی سەوز هەیە بە ناونیشانی
«سەرچاوەکانی ئەم بەشە» — بە کۆی گشتی ٤٠ بڵۆک. تەنها **کتێب** و
**ڕۆژنامە** وەک سەرچاوە تۆمار کراون، وەک داوا کراوە.

هەر بڵۆکێک سێ جۆر خاڵی تێدایە:

| جۆر | مانا |
|---|---|
| `کتێب …` / `ڕۆژنامە …` | سەرچاوەیەکی ڕاستەقینە کە زانیارییەکەی پێوە بەستراوە |
| `بۆچوونی نووسەر` | لێکدانەوەیە، نەک بەڵگە |
| `تێبینی …` | خاڵێک هێشتا پشتڕاست نەکراوەتەوە |

پێڕستی تەواوی سەرچاوەکان (١١ کتێب و ١٨ ڕۆژنامە) لە **پاشکۆی چوارەم**ی
کتێبەکەدایە.

هەر سەرچاوەیەک کە بەستەری هەبێت، بەستەرەکەی لە ژێریدا دانراوە و لە
Word ـدا کلیک‌کراوە. هەروەها هەر وێنەیەک بەستەرێکی هەیە بۆ ئەو شوێنەی
دەتوانرێت لەوێ بدۆزرێتەوە.

بۆ زیادکردن یان گۆڕینی سەرچاوەکان، `scripts/add_sources.py` بگۆڕە.

سێ خاڵی نادروست لە دەقی سەرەتاییدا ڕاست کراونەتەوە — بڕوانە بەشی چوارەمی کتێبەکە.
