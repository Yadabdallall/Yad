# فۆڕمی پێشکەشکردنی پڕۆژەی وەرزشی

فۆڕمێکی وێبی (HTML) بۆ **بۆردی وەرزشیی یەکێتیی نیشتمانیی کوردستان**.
کەسەکان فۆڕمەکە پڕ دەکەنەوە و بە کلیککردنی دوگمەی ناردن، هەموو زانیارییەکان
وەک نامەیەکی ڕێکخراو ڕاستەوخۆ دەچێتە وەتسئەپی ژمارە **0771 236 4141**.

## تایبەتمەندییەکان

- ٣ بەش: زانیارییە کەسییەکان، وردەکاریی پڕۆژە، دیدگا بۆ کەرتی وەرزش
- ناردنی خۆکار بۆ وەتسئەپ (`wa.me`) بە شێوازێکی ڕێکخراو
- پشکنینی خانە پێویستەکان پێش ناردن
- پاراستنی ڕەشنووس لە وێبگەڕەکەدا (ئەگەر لاپەڕەکە دابخرێت زانیارییەکان نافەوتێن)
- دوگمەی کۆپیکردن و سڕینەوە
- ئەگەر نامەکە زۆر درێژ بێت، خۆکارانە کۆپی دەکرێت و وەتسئەپ دەکرێتەوە
- فۆنتی **Rabar 008** و ڕەنگی ڕەسمیی یەکێتی
- تەواو گونجاو بۆ مۆبایل و کۆمپیوتەر

## پێکهاتەی فایلەکان

```
index.html                         لاپەڕەی سەرەکی (HTML + CSS + JS)
assets/fonts/Rabar_008.ttf         فۆنتەکە
assets/img/puk-logo.webp           لۆگۆی یەکێتیی نیشتمانیی کوردستان
assets/img/sports-board-logo.png   لۆگۆی بۆردی وەرزشی
assets/img/mam-jalal.jpg           وێنەی مام جەلال
```

## چۆن دایبنێم (hosting)

هیچ سێرڤەرێک پێویست نییە — تەنها فایلە ستاتیکەکانە:

- **Cloudflare Pages**: پڕۆژەیەکی نوێ دروست بکە و ئەم ڕیپۆیەی پێ ببەستەوە
  (Build command: بەتاڵ، Output directory: `/`)
- یان فۆڵدەرەکە بەرز بکەرەوە بۆ هەر هۆستێکی ستاتیکی تر (Netlify، GitHub Pages، هتد)
- بۆ تاقیکردنەوەی خێرا: فایلی `index.html` ڕاستەوخۆ لە وێبگەڕدا بکەرەوە
