# کیتی جوڵە و فۆنت و ڕەنگی فۆڕمی بۆردی وەرزش

هەموو ئەو شتانەی لە پەڕەی فۆڕمەکەدا بەکارهاتوون — فۆنت، ڕەنگ، جوڵە و پارچەکان —
جیا کراونەتەوە بۆ ئەوەی لە هەر پڕۆژەیەکی تردا بەکاریان بهێنیتەوە.

---

## ١. ناوەڕۆکی زیپەکە

```
demo.html            نموونەیەکی کارا — هەموو جوڵەکان بە چاو دەبینیت
css/fonts.css        فۆنتی Zain (@font-face)
css/tokens.css       ڕەنگ و بنەمای لاپەڕە (گرنگترین فایل)
css/motion.css       هەموو جوڵەکان
css/components.css   بانەر، لۆگۆ، کارت، خانە، دوگمە، پێپەڕ، لیدەکان
js/motion.js         کۆدی جوڵەکان
fonts/*.woff2        شەش فایلی فۆنت (٤٠٠/٧٠٠/٩٠٠ × عەرەبی+لاتینی)
```

**سەرەتا `demo.html` بکەرەوە** — هەموو شتەکان بە کردار دەبینیت.

---

## ٢. چۆن بەکاری بهێنیت

لە `<head>` ـی لاپەڕەکەتدا، بەم ڕیزبەندییە:

```html
<link rel="stylesheet" href="css/fonts.css">
<link rel="stylesheet" href="css/tokens.css">
<link rel="stylesheet" href="css/components.css">
<link rel="stylesheet" href="css/motion.css">
```

لە کۆتایی `<body>`:

```html
<script src="js/motion.js"></script>
```

لاپەڕەکە دەبێت `dir="rtl"` بێت:

```html
<html lang="ckb" dir="rtl">
```

## ٣. جوڵەکان — تەنها بە زیادکردنی کلاس

| کلاس | چی دەکات |
|---|---|
| `reveal` | پارچەکە بە نەرمی لە خوارەوە بەرز دەبێتەوە. **یەک جار** ڕوودەدات، دوایی دەوەستێت. |
| `reveal lines` | دەقەکە **دێڕ بە دێڕ** لە پشت پەردەیەکەوە دێتە سەرەوە. بۆ پەرەگراف. |
| `reveal words` | دەقەکە **وشە بە وشە** دێت. بۆ ناونیشان. |

نموونە:

```html
<h2 class="reveal words">ناونیشانێک</h2>
<p class="reveal lines">پەرەگرافێک کە دێڕ بە دێڕ دێت.</p>
<div class="card reveal">کارتێک کە بە تەواوی بەرز دەبێتەوە.</div>
```

**تێبینی گرنگ:** `lines` دەقەکە دوای بارکردنی فۆنتەکە دەپێوێت، بۆیە لەگەڵ هەموو
قەبارەیەکی شاشەدا ڕێک دەبێت، وە لەگەڵ گۆڕینی قەبارەی پەنجەرەکەشدا خۆی
دروست دەکاتەوە.

### جوڵەکانی تر

- **لیدەکانی لای پەڕە** — `nav.stepper` + دوگمەی `.step`. ژمارەی `.step`ەکان
  دەبێت یەکسان بێت لەگەڵ ژمارەی `.card`ەکان. خۆیان پێدەکەون و نیشان دەدەن
  کام بەش لەبەردەستە، وە بە کلیک دەچنە سەری.
- **کردنەوە بە پەنجەلێدان** — `#boardLogo` → `#logoNote` دەکاتەوە،
  `#devName` → `.footer`ی دەکاتە `is-open` (ناوەکە درەوشانەوەی زیاتر دەبێت و
  دێڕی ژێری دەردەکەوێت).
- **کردنەوەی لاپەڕەکە** — `.banner` و `.wrap` بە نەرمی دێنە ناوەوە (`page-in`).

### بەبێ JavaScript

هەندێک بینەری فایل (وەک پێشبینینی iOS) JavaScript ناخەنە کار. بۆ ئەو حاڵەتە،
`motion.css` هەمان دەرکەوتن بە CSS ـی تەنها ئامادە دەکات، وە لە وێبگەڕە نوێیەکاندا
`animation-timeline: view()` بەکاردێت بۆ بەستنەوەی ڕاستەوخۆ بە سکڕۆڵەوە.

### `prefers-reduced-motion`

ئەگەر بەکارهێنەر لە ڕێکخستنی ئامێرەکەیدا جوڵەی کەم داوا بکات، هەموو جوڵەکان
خۆیان کورت دەکەنەوە یان دەوەستن. ئەمە خۆکارە.

## ٥. فۆنتی Zain

- شەش فایل: قەبارەی **٤٠٠ (ئاسایی)، ٧٠٠ (تۆخ)، ٩٠٠ (زۆر تۆخ)** — هەریەکەیان
  دوو فایل: یەک بۆ کوردی/عەرەبی، یەک بۆ لاتینی.
- `unicode-range` وا دەکات وێبگەڕ تەنها ئەوەی پێویستە دایبەزێنێت.
- **تێبینی:** لە Zain ـدا ژمارە کوردییەکان (٠١٢٣) بە شێوەی ژمارەی لاتینی (0123)
  دەردەکەون — ئەمە دیزاینی خودی فۆنتەکەیە.
- مۆڵەت: SIL Open Font License (Google Fonts) — بەکارهێنانی ئازادە، بۆ
  بازرگانیش.
