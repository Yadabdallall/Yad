زیادکردنی فۆڕم لە PDF

بۆ ئەو فۆڕمانەی بە خۆکاری نەگەیشتوون: PDFـەکان لە واتسئاپ پاشەکەوت بکە (Save to Files) و لێرە هەڵیانبژێرە — دەتوانیت چەندانێک پێکەوە هەڵبژێریت. هەر PDFێک تەنها یەک جار هەژمار دەکرێت، و ئامارەکان لەسەر ئەم ئامێرە دەمێننەوە.

یان: کۆکردنەوەی خۆکار بە Google Sheet (ئارەزوومەندانە)
  1. بە ئەکاونتی Googleی بۆرد، Google Sheetێکی نوێ دروست بکە.
  2. لە شیتەکەدا: Extensions → Apps Script. کۆدە کۆنەکە بسڕەوە.
  3. ئەم دوگمەیە دابگرە و کۆدەکە لەوێ دابنێ، پاشان Save بکە:
  4. فەنکشنی setup هەڵبژێرە و Run بکە و مۆڵەت بدە.
  5. Deploy → New deployment → Web app؛ Execute as: Me، Who has access: Anyone. لینکی Web App کۆپی بکە.
  6. ئەم فایلە بە Notepad بکەرەوە و لینکەکە لە const SCRIPT_URL = "" دابنێ.
  7. فایلەکە لەسەر ماڵپەڕی بۆرد بار بکە. هەمان لینک بۆ نوێنەرەکانە؛ ئیدارەش #admin لە کۆتایی لینکەکە زیاد دەکات.

ناردنی خۆکاری PDF بۆ واتسئاپی بۆرد

  1. لە business.facebook.com و developers.facebook.com ئەپێکی WhatsApp دروست بکە و ژمارەیەکی دووەم وەک نێرەر زیاد بکە. ژمارەی بۆرد وەرگر دەبێت و وەک خۆی دەمێنێتەوە.
  2. تێمپلەیتی activity_form دروست بکە: Utility، زمان Arabic، Header بە جۆری Document، Body بە چوار گۆڕاو: ژمارەی تۆمار {{1}}، نوێنەر {{2}}، ناوچە {{3}}، چالاکی {{4}}.
  3. لە Apps Script: Project Settings → Script Properties: WA_TOKEN و WA_PHONE_NUMBER_ID زیاد بکە.
  4. testWhatsApp ڕابکە بۆ تاقیکردنەوە، پاشان Deploy → Manage deployments → New version.
